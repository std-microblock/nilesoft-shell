Morpthis Shell 

[about]
Morpthis Shell is a powerful, lightweight extension for Windows File Explorer that gives the user a high level of control over the context menu to improve its performance. 
Compatible with Windows 7 or later.

[update]
(*) If you are updating, please first uninstall/unregister previous version.
