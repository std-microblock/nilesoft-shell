Installation


Info: Administrative permissions are required for installation.

Shell can be installed in the following ways:

  • Installer
  • Portable

Please also note the following reference sections:

  • Command-Line Help
  • Keys to enable/disable Shell functionalities

Installer version
Install

Download the latest build from the GitHub Actions page (artifact morpthis-shell-x64 or morpthis-shell-x86), run the installer, follow the installation steps, and agree to restart Windows File Explorer.

The program will be installed to C:\Program Files\Morpthis Shell\, unless you have chosen a different installation path during the installation steps.

Uninstall

Inside the Shell program folder (C:\Program Files\Morpthis Shell\ by default), run the unst000.exe or unstall.exe file, then follow the steps, and then agree to restart Windows File Explorer.


Portable version
Install

Download the latest build from the GitHub Actions page (artifact morpthis-shell-x64 or morpthis-shell-x86) and extract it to the folder you want to run the program from.

Open an elevated command prompt (or use gsudo), change to the directory you have extracted the program to, and run

Administrator: Command Prompt
morpthis -register -restart

For further details, see the chapter Command-Line Help below.

Uninstall

Open an elevated command prompt (or use gsudo), change to the directory you have extracted the program to, and run

Administrator: Command Prompt
morpthis -unregister -restart

Tip: Close all instances of Windows File Explorer before uninstalling to avoid needing a reboot after it (Shell) has been uninstalled.

For further details see the chapter Command-Line Help below.


Command-Line Help

morpthis -[options]

Options
-register (-r) Registering.
-unregister (-u) Unregistering.
-restart (-re) Restart Windows Explorer.
-treat Disable Windows 11 context menu.
-silent (-s) Prevents displaying messages.
-? Display this help message.
Use the following keys to enable/disable

These keys are used when you press right-click or press Shift+F10 keys

CTRL To enable and reload the configuration file morpthis.nss
WIN To make priority to the modern context menu for Windows 11
CTRL+WIN To disable Shell and Enable Classic Context Menu
RIGHT-CLICK+LEFT-CLICK To reload the configuration file morpthis.nss
